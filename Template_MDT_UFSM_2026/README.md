# Instruções

1. Faça download deste repositório ou desta pasta
2. Uma vez já baixada, compacte esta pasta para um arquivo .zip
2. Abra o [Overleaf](https://overleaf.com)
3. Clique em **New project**, e depois selecione **existing project (.zip)**
4. Faça upload do zip deste projeto
5. Renomeie o projeto para algo da sua preferência
